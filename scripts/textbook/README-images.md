# Изображения учебника

- `src/data/textbook-images.json` содержит готовые ссылки на миниатюры Wikimedia Commons, авторов и лицензии. Сайт не ищет картинки во время открытия урока.
- `src/lib/textbook-images.ts` сначала ищет проверенное изображение точной темы, затем применяет тематические правила. Если подходящего изображения нет, показывает фото по предмету с явной подписью.
- Скрипт `python3 scripts/textbook/build_image_catalog.py` обновляет каталог офлайн по текущим темам. Он допускает только изображения с открытыми лицензиями и сохраняет ссылку на исходный файл. Перед публикацией новых подборок нужно просмотреть спорные совпадения: заголовки в Википедии бывают многозначными.
- Авторы и лицензии показаны под иллюстрациями уроков и заголовков предметов. Для миниатюр в каталогах есть раскрывающийся список источников на той же странице.
