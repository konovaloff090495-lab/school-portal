# Воронка вечерних школ и аттестата

Выпуск 22.10.2026 основан на анализе страниц входа, заявок и сопоставленных CRM-статусов. Изменения — внедрение гипотез, а не доказанный результат A/B-теста.

## Что проверяем

- Явный выбор местной школы / платной онлайн-программы до списка карточек повышает долю подходящих обращений. Основная метрика — сделки на 1000 целевых визитов; контроль — причины «Офлайн», дозвон и завершение формы.
- Маршруты к аттестату за 9 и 11 класс и необязательные уточнения в форме помогают консультанту начать разговор с нужной программы.
- Страница 9 класса отвечает на задачу окончания основной школы. «После 9 класса» отвечает на поступление в 10 класс, «10–11 классы» — на выбор полной старшей программы. Не создавать дубли с одинаковыми списками и текстами только ради количества URL.
- Контекстные ссылки из взрослого блога и новые метаданные городских страниц помогают поисковику и посетителю выбрать подходящую страницу. Показы в GSC означают участие в выдаче в прошлом окне, а не необходимость повторно включать URL в индекс.

## Атрибуция

`YandexMetrika` вызывает `rememberUtm` на входе и при внутренней навигации. В рамках вкладки сохраняются первая страница без query-параметров, первый реферер и первые найденные UTM. При отправке отдельно передаётся текущая страница. Если браузер запрещает sessionStorage, неизвестный первый вход не подменяется текущей страницей.

`submitLead` → API → `sendLeadToSynergy`: form_id, product, qualification, page_url, landing_url, first_referrer, ym_client_id. Источник партнёра gerasimov_lav сохраняется. Исходные UTM не затираются в customAttributes. Если utm_content у посетителя отсутствует, в стандартное поле попадает путь страницы отправки. Комментарий CRM включает текущую страницу перед страницей входа.

Приватный журнал хранит ответ CRM с её ID. Не размещать журнал, контакты, комментарии или выгрузку CRM в public/ или Git. Не считать заявку принятой только по клику или открытию страницы благодарности.

Сверка с CSV CRM по точному ID, без вывода контактов:

```bash
python3 scripts/leads-growth/reconcile.py --journal /private/path/lead-journal.jsonl --crm-csv /private/path/crm.csv --output /private/path/pages.csv
```

Числа со статусом без сопоставления не подставляются как нулевые сделки. Скрипт не определяет оплаты: для них нужен отдельный подтверждённый ключ. Сравнивать когорты одинакового возраста и одинаковые окна дат. При малой выборке не объявлять 1/1 победителем.

## Проверки

```bash
node scripts/leads-growth/check.mjs
node scripts/seo-school-formats/check.mjs
npm run lint:leads
npx tsc --noEmit --incremental false
python3 scripts/check-navigation-policy.py
node scripts/leads-growth/check-http.mjs
```

Последняя проверка запускает готовую production-сборку, проходит страницы на пяти ширинах и перехватывает отправку формы в браузере. Настоящие CRM-заявки и письма не отправляются. Выпуск собирается существующим GitHub Actions; локальная тяжёлая сборка не требуется.

## Второй пакет 22.10.2026

- Проверены объявления приёма центра №185 Екатеринбурга (21.05.2026) и №195 Санкт-Петербурга (25.06.2026, 2026/27); источники и границы проверки хранятся в `src/data/evening-admissions-verified.json`. Это не подтверждение свободных мест или бюджетного приёма каждого заявителя. Блоки находятся перед списками в городах, общем вечернем хабе и существующей подборке бесплатных вариантов.
- У двух карточек уточнены название/классы/контакты; три записи с известными обращениями явно помечены как требующие подтверждения. Не удалять их и не заменять выдуманными организациями из-за отсутствия результата поиска.
- Четыре существующие статьи про аттестат и выбор формата переписаны: документы → формат → условия → подходящая программа. Обложки и подписанные иллюстрации сохранены. Не создавать ещё одну страницу сравнения с тем же интентом.
- Онлайн-хаб ведёт к полному школьному году, взрослому аттестату или отдельным предметам до большой таблицы. Текущая средняя позиция Google около17 и187показов — основание улучшать эту страницу, не доказательство будущего роста.
- Общая ученическая форма и каталожный попап предлагают необязательное время звонка по Москве; поля передаются в CRM. Нет неподтверждённого обещания ответа за30минут. Выбор9/11из ссылки предзаполняет взрослую форму. Основные поля и согласия сохранены.
- Метрика: `growth_route_view`, `growth_route_click`, `growth_form_start`, `growth_form_error`. Показы — первое попадание20%блока в видимую область на странице; начало/ошибка — не более одного раза на экземпляр формы. Это микроконверсии, не новые заявки и не сделки. Значения контактных полей не передаются. Клики содержат только разрешённые коды маршрутов; `selected_route` и `growth_release=leads-growth-20261022-r2` проходят в CRM/приватный журнал. Первая страница и исходные UTM не меняются.

Измерение: больше подходящих визитов и сделок на1000визитов; отдельно смотреть начало/завершение формы, причины отказов и дозвон по когортам одинакового возраста. Выбор времени не гарантирует фактический SLA менеджера — его нужно оценивать по данным контактов CRM. Релиз представляет пакет гипотез; эффекты отдельных блоков нельзя выделить сравнением «до/после» без учёта сезонности и других релизов.
