# Письма по заявкам pro-schools.ru

## Когда отправляются

- Сразу после принятия заявки CRM: одно письмо с карточкой школы. Партнёрские ссылки показываются только при явном согласии на маркетинг.
- При согласии в базе появляется запись `pending`. Ссылка из приветствия открывает страницу подтверждения, затем человек нажимает кнопку. До подтверждения других писем нет.
- После подтверждения — четыре тематических письма через 7, 21, 35 и 49 дней: форматы школы, экзамены, детские курсы, поступление. Вместе они охватывают 21 продукт school-university.com.
- Отписка по ссылке срабатывает сразу и навсегда; повторная заявка её не отменяет. Старые заявки автоматически не импортируются.

## Ограничения

- Отправка только через `hello@pro-schools.ru` с SMTP Beget.
- Не более 10 тематических писем за запуск, 20 за сутки; запуск дважды в день. Одно письмо на адрес в одном этапе. Для мгновенного приветствия отдельный лимит: 10 в минуту, 100 в сутки и 3 на один адрес в сутки.
- Ошибка SMTP приостанавливает кампанию до ручной проверки. Ошибка конкретного адреса исключает его.
- В письмах есть текстовая и HTML-версии, заголовок `List-Unsubscribe`, прямая ссылка отписки и партнёрская UTM `utm_source=gerasimov_lav`.
- База `.crm-mailer.sqlite3` находится только на VPS, имеет права 600 и не попадает в Git. В логах нет адресов и имён.

## Управление на VPS

```bash
cd /var/www/school-portal
python3 scripts/crm-mailer.py status
touch .crm-mailer-paused               # сразу остановить плановую отправку
rm .crm-mailer-paused                  # возобновить после проверки
python3 scripts/crm-mailer.py run      # ручной запуск с теми же лимитами
```

Расписание root crontab (UTC, 10:00 и 15:00 МСК):

```cron
0 7,12 * * * cd /var/www/school-portal && /usr/bin/flock -n /tmp/proschools-crm-mailer.lock /usr/bin/python3 scripts/crm-mailer.py run >> /var/log/school-portal/crm-mailer.log 2>&1 # proschools-crm-mailer
```

DKIM Beget для SMTP включается через обращение в поддержку из панели Beget. До его включения нужно следить за доставкой и не повышать лимиты.
