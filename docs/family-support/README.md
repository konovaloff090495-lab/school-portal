## Генерация

`python3 scripts/family-support/build.py` обновляет только перечисленные статьи,
локальный манифест и статический каталог. Источник редактирования — три measures
JSON и retained-content с сохранёнными полезными школьными разделами.
Новые формы и персональные анкеты не добавлены. Каталог получает каноническую
навигацию и Метрику; статьи используют существующий native blog/[slug].

`python3 scripts/family-support/semantics.py` создаёт CSV/JSON таблицы в
`outputs/family-support/`. Пользовательская XLSX создана bundled Artifact Tool:
6 листов, числовые частоты/даты, фильтры и закрепление заголовков. Исходные
наблюдения и ассоциации сохраняются отдельно. Широкие частоты не суммируются.

## Публикация

`preflight.py` проверяет runtime root, каноническую навигацию и четыре существующих

- сливает live-манифест, поиск и sitemap по ключам, сохраняя посторонние записи;
- публикует каталог отдельным статическим выпуском и точным location Nginx;
- проверяет Nginx перед reload и SHA фактического ответа каталога;
- вызывает авторизованный revalidate статей, читая секрет только на VPS.

Сохранять `/etc/nginx/snippets/proschools-family-support.conf` при замене конфигурации.
