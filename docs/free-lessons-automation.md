## Два уровня

1. На VPS `proschools-free-lessons.timer` запускает `run.sh` каждые 30 минут.
   Пересчитываются ближайшие 22 дня еженедельного расписания, прошедшие разовые события
   уходят из каталога/поиска/sitemap. В открытой вкладке JS дополнительно проверяет время.
   Записи и занятия по индивидуальной записи не считаются прошедшими по выдуманной дате.
2. Источники проверяются раз в 6 часов с ограничением запросов, allowlist HTTPS и robots.txt.
   Подтверждённые слоты своих 23 уроков обновляются автоматически. Новые предложения попадают
   в persistent pending. Дважды в день агент этого чата проверяет новые карточки, создаёт
   уникальные обложки и публикует до 5 подтверждённых предложений за один запуск.

Сами расписания/архивация работают на сервере, независимо от Mac. Проверка новых программ
и создание обложек — heartbeat Codex, на доступном исполнителе этого чата.

## Источники и ограничения

`scripts/free-lessons/sources.json`: официальный Лекторий School University, все реально
найденные страницы бесплатного каталога Умскул (не более 20 за проход), открытые события
Фоксфорда и текущие страницы партнёров. Новые даты только из полного недельного расписания
или явного Event с часовым поясом и нулевой ценой; названия, год и возраст не угадывать.
HTTP403/401/таймаут/ошибка разметки не удаляют существующие предложения.
Два полных подтверждённых расписания без прежнего урока снимают его с афиши.
После 7 дней без подтверждения недельного расписания собственный урок не получает бесконечно
выдумываемые даты: карточка скрывается, форма блокируется до обновления источника.
Переносы и каникулы, не опубликованные организатором, система знать не может.

## Состояние и публикация

- Код VPS: `/var/www/school-portal/free-lessons-runtime`.
- Приватное состояние без заявок: `/var/lib/proschools-free-lessons`.
- `catalog.json` — все записи, включая архив; `state.json` — pending и результаты источников.
- `last-run.json`, `runs.jsonl`, `published.json`, `publications.jsonl`, `history/` — журнал и версии.
- Факты истории не удаляются. Хранятся 20 последних автоматически собранных релизов;
  старые ручные релизы не затрагиваются. Обложки неизменяемы, имена новых файлов уникальны.
- `pipeline.lock` предотвращает одновременные обновления и импорт карточек.
- Проверенный релиз атомарно переключает только `free-lessons-current`. Next не собирается
  и не перезапускается. При неуспешной HTTPS-проверке указатель возвращается назад.
- Новые страницы должны иметь уникальные title/description/canonical, одну шапку/подвал
  из актуального `src/site-navigation/chrome.json`, правильный JSON-LD и рабочие ссылки.
- Прошедшие страницы сохраняют URL, показывают завершение, имеют noindex и не принимают
  регистрацию. Сводные пустые темы тоже noindex. Пагинация пересчитывается.
- Общий поиск загружает свежий `/besplatnye-uroki/search-index.json` поверх базового индекса:
  прошедшие записи не застревают в нём, другие разделы не меняются.
- Браузер использует прежний submitLead/CRM, собственные source ID сохраняются.
  Не создавать регулярные тестовые лиды. Доставка уже подтверждена тестом233506.

## Остановка и восстановление

Пауза обоих уровней: создать `/var/lib/proschools-free-lessons/PAUSED`.
Снять паузу: убрать только этот файл по запросу пользователя.
Таймер: `systemctl disable --now proschools-free-lessons.timer`.
Heartbeat можно отключить в Codex; его id фиксируется в памяти проекта.
Откат: взять previous из published.json и атомарно вернуть free-lessons-current;
не трогать .next, CRM, courses-current и programming-current.
