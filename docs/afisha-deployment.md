# Афиша ProSchools — рабочий раздел

Опубликовано 31.10.2026: `/afisha/`, 225 городов России и 12 категорий в каждом.
Отдельный хаб `/afisha/moskovskaya-oblast/` включает все 74 города области;
городские адреса имеют вид `/afisha/moskovskaya-oblast/balashikha/`.
Москва — `/afisha/moskva/`. Мероприятия: `<город>/sobytie/<source-id>/`.
Точные события и подписанные альтернативы не смешиваются в счётчике.

## Сервер и периодичность

Используется только чистый VPS `portfolio-admin@155.212.140.76` с ключом
`~/.ssh/portfolio_security_20261024`; при необходимости `BindInterface=en0`.
Скомпрометированный старый сервер не использовать.

- Код: `/srv/portfolio/proschools/static-runtime/afisha`, root-owned.
- Состояние и кэш: `/var/lib/portfolio/proschools-afisha`.
- Выпуски: `/srv/portfolio/proschools/static/afisha/releases/`.
- Атомарный указатель: `/srv/portfolio/proschools/static/afisha/current`.
- Служба: `portfolio-afisha-refresh.service`, пользователь `site-proschools-publisher`.
- Таймер: `portfolio-afisha-refresh.timer`, `OnUnitActiveSec=2d`, автозапуск после загрузки.
- Обновление на компьютере в автоматизации `proschools-9` приостановлено.

Служба ограничена 768 MiB RAM, 700 MiB MemoryHigh, 50% CPU, Nice=10,
имеет запись только в своё состояние и каталог выпуска. Файлы доступов других
приложений закрыты. Секреты не входят в исходники или публичный каталог.
Конфигурация публичного доступа Tripster из официальной документации Travelpayouts
передаётся через закрытый `/etc/portfolio/afisha.env`; токен API живёт в памяти.
Партнёрские ссылки ProSchools ещё не активированы: переходы ведут на исходные программы.

```sh
sudo systemctl status portfolio-afisha-refresh.timer
sudo systemctl list-timers portfolio-afisha-refresh.timer
sudo journalctl -u portfolio-afisha-refresh.service -n 40 --no-pager
sudo systemctl start portfolio-afisha-refresh.service
```

Публичный результат последнего успешного обновления:
`https://pro-schools.ru/afisha/refresh-status.json`.
Покрытие: `/afisha/status.json`; sitemap: `/afisha/sitemap.xml`.
Первая полная серверная загрузка источников, проверка и публикация завершены;
ошибки импорта окружения и прав на переключение указателя исправлены.
Временная команда продолжения первой публикации удалена из `/run/systemd/system`:
штатный ExecStart — `refresh.py`, не `resume.py`.

## Пайплайн

`refresh.py` читает Culture.ru и Afisha.ru, проверяет возрастные цензы,
добавляет Quick Tickets и официальные локальные планы, затем получает детские
программы и календари Tripster. `data.py` отделяет факты городов и области,
а `build.py` переносит их в согласованный общий интерфейс. Для отсутствующего
расписания не создаются фиктивные ежедневные сеансы. Исчезновение программы
не означает отмену: её опубликованный URL и исходные сведения сохраняются.

До переключения проверяются непустая база, уникальные ID, исключение 18+,
покрытие 225 городов и всех 74 городов области, страницы и синтаксис приложения.
При ошибке действующий выпуск остаётся на сайте. Сохраняется предыдущий выпуск
для отката. На сервере перед генерацией проверяется свободное место; минимум 550 MiB.

HTML, городские данные и приложения хранятся с gzip, рядом — нулевые файлы-маркеры.
Nginx обслуживает их через `gzip_static always; gunzip on`; это экономит диск,
сохраняя обычные URL и работу клиентов без Accept-Encoding. При проверке файлов
на диске читайте соответствующий `.gz`. Проверка JS в службе распаковывает его
и передаёт `node --check` через stdin.

Галереи и превью используют опубликованные изображения конкретной программы.
Карты — только Яндекс. Если точка не опубликована, вместо поисковой карты показаны адрес/ориентир
и ссылка для уточнения у организатора. Радиус применяется только к площадкам с координатами.
Справочники Москвы не используются вместо справочников других городов.
Данные метро получены из открытого справочника HH; районы — из источников проекта.

## Навигация и измерение

Канон — `src/site-navigation/chrome.json`, семь верхних пунктов. Учебник и ГДЗ
объединены в одну группу, добавлена Афиша. Порядок desktop и mobile совпадает.
Общая навигация обслуживается из `/srv/portfolio/proschools/static/navigation/`;
Nginx использует отдельный location, поэтому не нужна пересборка основного Next.
Общий runtime синхронизирует канонические фрагменты на уже собранных страницах.
Кнопки выбора школы продолжают вести в `/shkoly/`, включая мобильное меню афиши.

Используется существующий счётчик Метрики 108789843. Переходы внутри афиши
регистрируются как просмотры; `q` исключён из URL, передаваемого этим обработчиком.
Сохраняются существующие `ps_utm` и `ps_visit_entry_v1` для лид-форм основного сайта.

```sh
python3 scripts/check-navigation.py
python3 -m py_compile scripts/afisha/*.py scripts/afisha/collectors/*.py
```

## Проверка каталога 31.10.2026

Главные городские страницы теперь содержат `guide.py`: категории с фактическими
счётчиками, местные площадки и рекомендации по посещению. Блок включён в исходный
HTML и в городские данные для интерактивного интерфейса. Перелинковка сохраняет
все города в обычных ссылках, но группирует их в раскрывающиеся алфавитные списки
с поиском; отдельно показаны несколько крупных городов.

Координаты собираются для всего каталога тремя коллекторами: `venue-geo.py`
(официальный Culture API учреждений), `afisha-venue-geo.py` (главная сущность площадки)
и `event-venue-geo.py` (точное место из Culture API события). Все три включены
в серверное обновление раз в 48 часов. Кэш опубликованных точек — 30 дней,
неразрешённых — 2 дня; сбой источника не очищает сохранённый кэш.

`geodata.py` проверяет идентичность источника и адреса; центр города и соседние
рекомендации источника не используются. Между источниками разрешено совпадение
только в одном городе по точному нормализованному адресу с номером дома,
при отсутствии конфликта координат. Пять ручных подтверждений площадок хранятся
в `seeds/verified-venue-locations.json` с URL первоисточника и временем проверки.

координаты площадок; 236 экскурсий Tripster публикуют только ориентир встречи.
Их точка не выдумывается, показано явное уточнение у организатора.

Скрытые географические поля не оставляют неподписанных выпадающих списков.
