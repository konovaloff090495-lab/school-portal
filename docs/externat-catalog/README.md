# Каталог экстернатов — 27.10.2026

Запрос владельца: собрать школы по городам, исправить повторяющиеся обложки и перенести ссылки из большого вводного блока в фильтры.

Вместо 32 карточек — 157 предложений: 123 местных школ/площадок в 71 регионе каталога и 34 дистанционных программы. Создана 83 новые карточки; остальные предложения переиспользуют существующие карточки других типов. Пригородные площадки сохраняют собственный город в поле city. Дистанционная школа учитывается один раз по России и доступна в городских подборках без создания вымышленных филиалов. Это проверенное расширение, а не заявление о полном охвате рынка.

Источники и ограничения: [sources-2026-10-27.json](sources-2026-10-27.json). В подборку включены все 18 учреждений, названных в официальном петербургском перечне. Для центра №80 использована отдельная «Рождественская школа», а не одноимённая школа английского языка.

Сеть ТОП: 70 городских площадок, проверены местные адреса и ссылка на услугу аттестации. Прикрепление оформляется к московской школе; адрес площадки не считается местом ГИА. У отдельных городских страниц услуги прямой HTTP-запрос возвращает 403; условия общей программы дополнительно просмотрены через веб-поиск на официальных страницах Томска, Ижевска, Саратова и Калининграда. Не подтверждённые адреса и будущий набор 2027/28 не добавлялись.

Из подборки исключены пять дублей, центр дополнительного профессионального образования и три семейных класса без подтверждённой аттестации, а также репетиторский центр «Экстерн» (Ростов-на-Дону), у которого подтверждены только курсы ЕГЭ/ОГЭ. Их карточки и URL сохранены. Ранее опубликованные муниципальные записи без новой проверки приёма сохранены; им не приписывается ускоренная программа. Для независимой проверки лицензий и свободных мест нужны отдельные подтверждения.

Для всех 157 карточек заданы разные основные и резервные изображения: 38 официальных изображений/фото, остальные — подписанные иллюстрации. Источники, хеши, метод и полный prompt одной новой генерации встроенным image_gen: [images-2026-10-27.json](images-2026-10-27.json). Использована также существующая библиотека сгенерированных редакционных сцен. Портреты сотрудников ТОП и общие для сети интерьеры не выдаются за фотографии конкретной площадки. Существующие галереи сохранены.

Класс, формат и условия вынесены в фильтры. Пояснение об аттестации находится в компактном раскрывающемся блоке после карточек, в сетке каталога. Ссылки на 9 класс, 10–11, онлайн, бесплатную аттестацию и материал для взрослых остаются обычными ссылками внутри нативного details, присутствуют в серверном HTML. Политика индексации учитывает местную школу, а не только дистанционные альтернативы. Формы, согласия и маршрутизация CRM не изменены.

Проверки:

- `node scripts/externat-schools/check.mjs` — источники, уникальность сущностей, разделение городов и национальных программ, 157 уникальных основных и резервных обложек.
- `node scripts/externat-schools/check-http.mjs` — 3 страницы × 5 ширин, фильтры, ссылки, порядок блоков, отсутствие горизонтальной прокрутки, HTTP/SHA256 всех обложек, две mock-отправки формы.
- Дополнительно действующие проверки онлайн-каталога, семейных школ, SEO, навигации и TypeScript в build-release.yml.

Скрипты collect.py и discover-top.py — только сбор кандидатов и снимков в work/, без автоматического изменения каталога. Новые площадки принимаются после проверки адреса и программы; названия рубрик в справочниках доказательством не являются.
