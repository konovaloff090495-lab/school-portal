# Общая навигация ProSchools

Утверждённый дизайн от 20.10.2026: единые шапка, подвал, мобильное меню,
самостоятельный поиск и «Ваш город» для всех страниц.

## Источник

- `src/site-navigation/chrome.json` — канонические HTML-фрагменты и версия.
- `public/site-navigation/navigation.css` — изолированные стили `.ps-chrome`.
- `public/site-navigation/navigation.js` — общая интерактивность, города и события.
- `public/site-navigation/search-index.js` — лениво загружаемый публичный индекс.
- React: `Header`, `Footer`, `NavigationRuntime` в корневом layout.
- Статические курсы: `scripts/courses/design/render.py` читает тот же JSON,
  подключает те же `/site-navigation/` ресурсы. Не использовать старые chrome/*.

- Программирование: `scripts/programming/build.py` также читает канонический JSON.

## Новые страницы, макеты и другие сессии

Новые React-страницы получают навигацию из root layout, без собственных шапок.
Новые статические генераторы обязаны встраивать канонические фрагменты на сервере,
с `.ps-chrome` и `data-navigation-version`, и подключать общие CSS/JS.
В новых макетах использовать те же фрагменты, стили и поведение. Менять только тело
страницы. Изменение общей навигации выполняется централизованно для всех рендереров.

Перед релизом: `python3 scripts/check-navigation.py`, typecheck, проверка
мобильного меню/поиска/города и desktop. Любой новый генератор добавить в проверку.

## Город

`selected_region` совместим со старым сайтом; URL города важнее сохранённого выбора.
Выбор в каталоге открывает городской каталог, на информационной странице меняет
предпочтение без ухода со страницы. Общие учебные материалы не фильтровать.
Первое приглашение можно отложить/закрыть; повторно на каждой странице не показывать.
Не запрашивать геолокацию и не подставлять выдуманный город.

## Измерение

Версия навигации: `2026-10-20.1`. События передаются в параметры визита Метрики
`navigation`: exposure, click с surface/target_section, поиск open/used/results_shown/
result_click, target_engaged (действие в содержимом или прокрутка после 10 секунд на странице назначения), город prompt_shown/selector_open/selected. Поисковый текст не передаётся.
Это новые данные; исторического CTR шапки нет. Старые автоцели не равны новым событиям.
База 22.09–19.10 сохранена в отдельном отчёте, сравнение до/после не доказывает причинность.
