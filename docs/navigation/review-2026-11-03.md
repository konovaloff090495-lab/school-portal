## Цели релиза и правила подсчёта

Главный показатель — доля визитов с полезным продолжением после навигации:
визиты с `navigation_target_engaged` / визиты с `navigation_exposure`.
Дополнительно — эта же доля среди визитов, использовавших навигацию/поиск.
Считать уникальные визиты и пересечение целей в одном визите; не делить число
всех достижений одной цели на число уникальных визитов другой.

`target_engaged` — приближённый сигнал: после перехода из общей навигации
на другую страницу посетитель взаимодействует с её содержимым или прокручивает
её после 10 секунд. Это не доказательство решения учебной задачи.

| Задача | Показатель | Желаемый результат |
|---|---|---|
| Найти нужное через навигацию | Полезное продолжение / экспозиция; отдельно / использовавшие навигацию | Больше осмысленных переходов, а не просто кликов |
| Сделать поиск доступным на телефоне | Визиты с использованием поиска / экспозиция, отдельно смартфоны | Поиск реально используется на мобильных |
| Поиск приводит к материалу | Визиты одновременно с использованием и переходом из поиска / использовавшие поиск | Высокая доля открытия результата; не только раскрытие поля |
| Снизить тупики поиска | Визиты с пустой выдачей / использовавшие поиск | Понятные причины пустой выдачи и приоритеты улучшения |
| Сделать подвал полезным | Визиты с показом и переходом из подвала / увидевшие подвал | Подвал помогает продолжить путь; учитывается его видимость |
| Выбор города с пользой | Сохранение / открытие выбора; затем локальный переход | Город помогает найти местное предложение, не мешает учебным материалам |
| Сохранить удобство сайта | Вовлечённость по сопоставимым сценариям/устройствам и доступность разделов | Нет ухудшения ключевых сценариев |

`site_search_used` учитывает ввод от двух символов, выбор готовой подсказки и
переход по найденному результату даже для односимвольного запроса. Показ подвала —
не менее 10% подвала в области просмотра, один раз на просмотр страницы.
Переход из подвала — внутренний переход на другую страницу; «Наверх» не считается.
Новые события настроены 20 октября, перечень 14 целей — `measurement-goals.json`.
Текст поискового запроса и точное местоположение не передаются в Метрику.

Не назначать произвольные проценты «победы» без исходного уровня. Показывать
числитель, знаменатель, долю, доверительный интервал и размер выборки. Для новых
метрик сформировать начальный ориентир следующего теста. Малые выборки обозначить
как недостаточные, не заменять нулями. Время и глубина не обязаны расти.

чем опираться на отказы/глубину. Не исправлять трекинг задним числом. Учесть рост
контента, источники, изменения сайта и возможное влияние осенних каникул.

раздельно не изолирован. Разрез surface показывает место действия, не причинность.

Итоговый отчёт: что сопоставимо и изменилось; первые результаты новых целей;
что осталось неизвестным; 3 приоритетных улучшения. Проверка только аналитическая —
без изменений сайта, целей, деплоя или запуска тяжёлой сборки.
