# Изображения и общий шаблон школ

С 22.10.2026 все `/shkola/<slug>/` обслуживает общий Next-шаблон
`src/app/shkola/[slug]/page.tsx`, как у школы «Президент». Не подменять их
статическими страницами программирования в Nginx. Каталоги программирования
продолжают работать самостоятельно; их ссылки ведут в общие карточки школ.

Приоритет изображений в карточках каталога и на странице школы:

1. Галерея реальных локальных файлов `/schools/<slug>-N.jpg`, проверенная в
   `src/data/school-media.json`, либо фотографии, загруженные представителем.
2. Локальная копия `og:image` официального сайта с подписью «С сайта школы».
   Изображение сети не считается фотографией конкретного филиала.
3. Тематическая иллюстрация из редакционного набора блога с подписью
   «Иллюстрация». Её не добавляем в photoCount или EducationalOrganization.image.

При ошибке всех файлов галереи показывается обложка. При ошибке официальной
обложки — иллюстрация. Ошибочные кадры исключаются из переключения галереи.
Изображения не подтягиваются из случайной выдачи по похожему названию школы.

Для обновления реестра и официальных изображений:

```
node scripts/schools/refresh-media.mjs --limit=90
node scripts/schools/check-media.mjs
```

`--source-public=/путь/public` позволяет проверить уже имеющиеся локальные фото
при работе в неполной рабочей копии. `--limit=0` обновляет только реестр фото
и три приоритетных официальных сайта; удалённые школьные картинки не заменяются.
Обязательно коммитить реестр вместе с новыми `public/schools/official/` файлами.
Проверка наличия всех ресурсов включена в облачную сборку.

Проверено 14 360 действующих школ: 3 729 с галереями, 817 с обложками официальных
сайтов, 9 814 с подписанными иллюстрациями. Автогенерируемые курсы новых страниц
сохранены как компактный список ссылок в `programming-school-courses.json`;
цены в нём не дублируются. При обновлении каталога курсов обновлять список из
активных программ с IT-тегами, использовать `course.id` как URL slug.
