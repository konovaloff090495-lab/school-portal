Курсы Python для детей

Python для школьников: первые программы, игры, боты и работа с данными. Выбирайте между базовым курсом и программой, которая требует опыта.

Проверьте, начинают ли с переменных, условий и циклов. Курс по ботам или Django предполагает другую подготовку, чем знакомство с языком. Для занятий обычно нужен компьютер, а не телефон.
